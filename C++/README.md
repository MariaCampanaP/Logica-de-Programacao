## ☕︎ Sobre a linguagem C
**C++** é uma linguagem de programação de **propósito geral**, amplamente utilizada no **desenvolvimento de sistemas, jogos, softwares de alto desempenho e aplicações que exigem controle eficiente de memória e processamento**. Derivada da linguagem C, C++ adiciona recursos poderosos como **Programação Orientada a Objetos (POO)**, tornando o desenvolvimento mais organizado, reutilizável e escalável.
Além de ser muito usada no **ensinoe de lógica e estrutura de dados**, C++ é essencial para áreas como **desenvolvimento de jogos, sistemas embarcados, computação gráfica, cibersegurança e aplicações desktop**. Entre seus principais conteúdos estão declaração de variáveis (como **int, float, double, char, string, entre outros**), operadores matemáticos, lógicos e relacionais, estruturas condicionais (**if, else if e else**), estruturas de repetição (**for, while e do while**), funções, vetores, e matrizes, manipulação de arquivos, ponteiros e alocação dinâmica de memória.
C++ também introduziu conceitos importantes de **Programação Orientada a Objetos**, como **classes, objetos, encapsulamento, herança e polimorfismo**, permitindo criar programas mais organizados e reutilizáveis. Apesar de exigir atenção com sintaxe, gerenciamente de memória e detalhes técnicos, **aprender C++ fortalece muito o raciocínio lógico e a base computacional do programador**.
É uma linguagem poderosa e versátil.

## Como clonar apenas esta pasta

Este repositório contém todas as 6 linguagens estudadas. Se quiser baixar **somente** a pasta "C++", use o sparse-checkout do Git:

```bash
git clone --no-checkout https://github.com/MariaCampanaP/Logica-de-Programacao.git
cd Logica-de-Programacao
git sparse-checkout init --cone
git sparse-checkout set "C++"
git checkout main
```
