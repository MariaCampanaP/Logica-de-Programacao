# ☕︎ Lógica de Programação

Repositório dedicado aos estudos e exercícios de lógica de programação, reunindo atividades práticas. O objetivo é consolidar os conceitos fundamentais de algoritmos e estruturas de programação, aplicando-os em diferentes linguagens à medida que o aprendizado avança.

## ☕︎ Linguagens 

| Linguagem | Status |
| --------- | ------ |
| Portugol  | ✅ Concluído |
| C         | ✅ Concluído |
| C++       | ✅ Concluído |
| Java      | 🔄 Em Andamento |
| C#        | ❌ Não Iniciado |
| Python    | ❌ Não Iniciado |

## ☕︎ Ferramentas utilizadas

- VisualG3;
- Code::Blocks;
- Visual Studio Code (VS Code);
- Java JDK.

## ☕︎ Objetivo

Praticar e fixar os fundamentos da lógica de programação: variáveis, estruturas condicionais, laços de repetição, vetores, matrizes e funções, evoluindo gradualmente da lógica estruturada (Portugol) para linguagens de propósito geral (C, C++, Java, C# e Python).

## Como clonar este repositório

```bash
git clone https://github.com/MariaCampanaP/Logica-de-Programacao.git
```

Isso vai baixar todas as 6 linguagens presentes no repositório.
Se quiser baixar apenas a pasta de uma linguagem específica, veja as instruções de sparse-checkout no README de cada pasta.
